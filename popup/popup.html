Apps Script Setup Guide:

  1. Go to script.google.com and click New Project.
  2. Copy & paste the code from the extension's folder (apps-script/code.js) into the editor.
  3. Click Deploy ➔ New deployment.
  4. Select Web app. Set Execute as to "Me" and Who has access to "Anyone".
  5. Click Deploy, copy the Web App URL, and paste it above!
